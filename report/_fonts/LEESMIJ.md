# Lettertypes voor de PDF

Meegeleverd zodat de PDF op elke computer identiek wordt opgemaakt, zonder installatie.

- **Source Serif 4** (lopende tekst), versie 4.005, Adobe. SIL Open Font License 1.1, zie `LICENSE_SourceSerif4.md`.
  Bron: https://github.com/adobe-fonts/source-serif/releases/tag/4.005R
- **Source Sans 3** (koppen, bijschriften, voetnoten), versie 3.052, Adobe. SIL Open Font License 1.1.
  Bron: https://github.com/adobe-fonts/source-sans/releases/tag/3.052R

De OFL laat toe de lettertypes mee te verspreiden in een repository en in te bedden in PDF's.
